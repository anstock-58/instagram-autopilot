# CTR-Framework — Entscheidungsbaum vor jeder Produktion

**Zweck:** Vor jedem Video in 30 Sekunden entscheiden ob es ein 0,5% oder 5% CTR Video wird.
**Regel:** Kein Video unter 3 Punkten produzieren. Thema neu formulieren oder verwerfen.

---

## BEWUSST EINFACH — Entscheidungsbaum

**Kern-Trigger:** Zahl + Mehrheit + Geheimnis + Autorität + Angst vor Verlust

### Schritt 1: Autoritäts-Check (Pflicht)

Hat das Thema mindestens EINEN dieser Autorität-Anker?

- Arzt ("Was dein Arzt nie sagt", "3 von 4 Ärzten")
- Wissenschaft/Studie ("Forscher haben gemessen", "Studien zeigen")
- Japan/Langlebigkeit ("Japanische Ärzte", "ältester Arzt", "Okinawa")
- Zahl ("87% schlafen falsch", "92% wissen es nicht")
- Zeit ("seit 50 Jahren", "seit Jahrzehnten bekannt")

**Kein Anker vorhanden = sofort stoppen.**

### Schritt 2: Risiko-Check (Pflicht)

Spricht das Thema direkt eine dieser Ängste an?

- Gehirnabbau / Demenz
- Schlafprobleme / Erschöpfung
- Körperabbau / Mobilität verlieren
- Früher sterben / kürzer leben
- Fehler machen der gesundheitlich schadet

**Keine Angst angesprochen = sofort stoppen.**

### Schritt 3: Zielgruppen-Check

Passt das Thema direkt auf 60 plus?

- Ja, explizit: "ab sechzig", "im Alter", "nach der Rente" → +2 Punkte
- Ja, implizit: Thema ist naturgemäß für 60+ (Schlaf, Demenz, Gelenke) → +1 Punkt
- Nein, generisch ohne Altersbezug → +0 Punkte, Thema umformulieren

### Schritt 4: Titel-Formel

Welches Muster passt auf den Titel?

| Muster | Punkte |
|--------|--------|
| Zahl + Fehler/Risiko ("87% machen diesen Fehler") | 3 |
| Arzt/Autorität + Geheimnis ("Was dein Arzt verschweigt") | 3 |
| Größte Lüge / Das weiß kaum jemand | 2 |
| Japan / älteste Menschen / blaue Zonen | 2 |
| Körperteil + Alter + Problem ("Dein Gehirn ab 60") | 2 |
| Allgemeine Gesundheitstipps ohne Trigger | 0 |
| Psychologie / Emotionen ohne Gesundheitsbezug | 0 |
| Storytelling ohne Nutzversprechen | 0 |

### Auswertung BewusstEinfach

| Gesamtpunkte | CTR-Prognose | Entscheidung |
|---|---|---|
| 7 bis 8 | ~5% — sehr hohes Potenzial | Produzieren |
| 5 bis 6 | ~2 bis 3% — solides Video | Produzieren |
| 3 bis 4 | ~1% — schwaches Video | Titel stark überarbeiten |
| 0 bis 2 | ~0,5% — nicht produzieren | Thema verwerfen |

## INNERCODE — Entscheidungsbaum

**Kern-Trigger:** Existenzielle Konfrontation mit Tod + persönliche Ansprache + Sinnauflösung

### Schritt 1: Tod-Check (Pflicht)

Ist Tod, Sterblichkeit oder Vergänglichkeit direkt oder stark implizit im Thema?

- Direkt: Tod, Sterben, letzter Tag, kurz vor dem Tod → +3
- Stark implizit: Zeit die vergeht, Leben das nicht gelebt wird, Verlust → +2
- Nur indirekt oder gar nicht → sofort stoppen

### Schritt 2: Persönliche Konfrontation (Pflicht)

Trifft der Titel den Zuschauer persönlich?

- "DU" direkt angesprochen ("Du stirbst gerade", "Du weißt es nicht") → +2
- Implizit ("Was Menschen kurz vor dem Tod bereuen") → +1
- Allgemein ohne persönliche Ansprache → +0

### Schritt 3: Schock plus Auflösung

Hat das Video beides?

- Klarer Schockeinstieg + Auflösung mit Hoffnung oder Klarheit → +2
- Nur Schock ohne Auflösung → +1
- Nur weiche Reflexion ohne Schock → +0

### Schritt 4: Titel-Formel

| Muster | Punkte |
|--------|--------|
| DU + Sterblichkeit + Unwissenheit ("Du stirbst gerade. Und weißt es nicht.") | 3 |
| Was Menschen am Ende bereuen / kurz vor dem Tod | 3 |
| Warum du X fühlst wenn jemand stirbt | 2 |
| Der Tod ist / bedeutet + neue Sichtweise | 2 |
| Psychologie ohne Todbezug | 0 |
| Allgemeine Selbstentwicklung ohne Existenz | 0 |
| Hochsensibilität, Selbstsabotage, Beziehungen (zu weich) | 0 |

### Auswertung InnerCode

| Gesamtpunkte | CTR-Prognose | Entscheidung |
|---|---|---|
| 9 bis 10 | ~5% — sehr hohes Potenzial | Produzieren |
| 6 bis 8 | ~2 bis 3% — gutes Video | Produzieren |
| 3 bis 5 | ~1% — zu weich | Titel und Thema schärfen |
| 0 bis 2 | ~0,5% — falsches Terrain | Thema verwerfen |

## Quick-Check: 30-Sekunden-Test

**BewusstEinfach:** Kann ich den Titel mit "Arzt sagt", "X% machen das falsch" oder "Das weiß kaum jemand ab 60" formulieren? Wenn nein — Thema verwerfen.

**InnerCode:** Kann ich den Titel mit "Du stirbst", "kurz vor dem Tod" oder "Was niemand dir sagt über dein Ende" formulieren? Wenn nein — Thema verwerfen.

## Themen-Selektion vor Produktion

**Bewusst Einfach — erlaubte Themenbereiche:**
Schlaf und Gehirn nach 60, Demenz vorbeugen, Langlebigkeit und blaue Zonen, Bewegung und Muskel ab 60, Gehirnnahrung und Ernährung, Herzgesundheit, Gelenke und Mobilität, Fehler die Altern beschleunigen, Autorität-Trigger (Arzt, Japan, Studie)

**Bewusst Einfach — verbotene Themenbereiche:**
Psychologie ohne Gesundheitsbezug, Emotionen, Beziehungen, Spiritualität, Funktionsmodus, generische Selbsthilfe, Storytelling ohne Nutzversprechen

**InnerCode — erlaubte Themenbereiche:**
Tod und Sterblichkeit direkt, was Menschen am Lebensende bereuen, Zeitverschwendung und Lebensversäumnis, Bewusstsein der eigenen Endlichkeit, Konfrontation mit dem eigenen Nicht-Leben

**InnerCode — verbotene Themenbereiche:**
Beziehungsthemen, Hochsensibilität, allgemeine Selbstentwicklung ohne Todbezug, Psychologie ohne existenzielle Konfrontation
