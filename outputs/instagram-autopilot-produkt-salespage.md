## WIE ES FUNKTIONIERT

**Drei Teile. Einmal einrichten. Dann läuft alles.**

**Eins — Contentplan ausfüllen**
Du trägst deine Posts für die nächsten Wochen ein: Datum, Caption, Videoprompt. Das war's.

**Zwei — Windows Task Scheduler**
Jeden Tag zur eingestellten Uhrzeit startet automatisch das Skript, liest den Plan und schickt den heutigen Post weiter.

**Drei — Make.com + KI**
Make.com empfängt den Post, ruft fal.ai auf (Kling v3 für Reels, Flux für Fotos), rendert das Textoverlay via Creatomate und postet direkt auf Instagram.

Kein Zutun. Kein Aufwand.

## FAQ

**Brauche ich Programmierkenntnisse?**
Nein. Die Anleitung führt dich Schritt für Schritt durch. Claude Code übernimmt die technische Einrichtung auf Basis des mitgelieferten Prompts.

**Was kostet das System laufend?**
Ca. 10–15 USD pro Monat für die KI-Generierung via fal.ai. Make.com ist im Free Tier kostenlos. Kein weiteres Abo.

**Funktioniert das mit meinem Instagram Account?**
Du brauchst einen Instagram Business Account. Den kannst du kostenlos in den Instagram-Einstellungen aktivieren.

**Muss ich Windows haben?**
Der automatische Daily-Trigger läuft via Windows Task Scheduler. Auf Mac lässt sich das Äquivalent mit einem Cron Job umsetzen — steht in der Anleitung.

**Was ist, wenn etwas nicht funktioniert?**
Die Anleitung enthält einen Troubleshooting-Abschnitt. Das System ist so aufgebaut, dass Fehler geloggt werden — du siehst immer, was passiert ist.
