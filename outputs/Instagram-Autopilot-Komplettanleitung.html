Einmal einrichten · Dann läuft alles von selbst

Du musst kein Techniker sein.

Claude Code übernimmt die komplette technische Einrichtung für dich. Du kopierst einen Prompt, beantwortest ein paar Fragen — Claude erledigt den Rest. Diese Anleitung zeigt dir genau was du wann tun musst.

🆘 Wenn du nicht weiterkommst

Bevor du jemanden fragst — frag zuerst Claude Code. Er kennt das System, weiß wie es funktioniert und erklärt dir jeden Schritt auf Deutsch. Das spart dir Zeit und du bekommst die Antwort sofort.

Wichtig zu wissen: Claude Code ist manchmal zurückhaltend — er wartet darauf, dass du ihn forderst. Hab keine Scheu. Frag nach. Sag ihm wenn du etwas nicht verstehst. Bitte ihn es einfacher zu erklären. Er erklärt alles auch für absolute Einsteiger — ohne Fachwörter, ohne Ungeduld, so oft du willst. Du kannst nichts falsch machen.

1

Accounts einrichten (einmalig · ca. 20 Min.)

Diese drei Konten brauchst du — sonst nichts:

  • Claude Pro — auf claude.ai/upgrade registrieren → · ab 15 €/Monat · Pflicht für Claude Code
  • Blotato — auf blotato.com registrieren → · ca. 26€/Monat · übernimmt Video, Captions, Voiceover und Publishing in einem
  • GitHub — auf github.com registrieren → · kostenlos · damit das System läuft wenn dein PC aus ist
  • Instagram Business Account aktiv? In den Instagram-Einstellungen unter "Konto" → "Zu Professional Account wechseln"
💡 Tipp: Blotato ersetzt alle anderen Tools komplett — kein fal.ai, kein Creatomate, kein Make.com nötig. Ein Tool, alles drin.
2

Claude Code installieren (einmalig · ca. 10 Min.)

  1. Gehe auf claude.ai/download
  2. Claude Code herunterladen und installieren
  3. Mit deinem Claude Pro Account einloggen
💡 Tipp: Claude Code ist wie ein sehr intelligenter Assistent, dem du auf Deutsch schreiben kannst was du brauchst — er erledigt dann alles für dich.
3

GitHub einrichten und mit Claude Code verbinden (ca. 15 Min.)

GitHub ist dein kostenloser Speicherort in der Cloud — und die Voraussetzung dafür, dass dein System auch läuft wenn dein PC aus ist.

Was ist GitHub?

Stell dir GitHub wie einen USB-Stick in der Cloud vor — deine Dateien sind sicher gespeichert und das System kann von dort aus täglich automatisch starten.

  1. Gehe auf github.com und erstelle einen kostenlosen Account
  2. Öffne Claude Code
  3. Kopiere den folgenden Text und füge ihn in Claude Code ein:
✂️ Diesen Text in Claude Code einfügen
Verbinde meinen Claude Code Workspace mit GitHub. Ich habe gerade einen neuen GitHub Account erstellt. Mein Benutzername ist: [DEIN GITHUB BENUTZERNAME]. Richte alles ein damit meine Dateien dort gespeichert werden.
💡 Tipp: Claude Code führt dich durch die Verbindung — du musst nichts selbst eintippen oder konfigurieren.
4

System aufbauen mit Claude Code (ca. 30 Min.)

Jetzt kommt der wichtigste Schritt — aber du musst nichts selbst programmieren. Kopiere einfach den folgenden Text und füge ihn in Claude Code ein:

✂️ Diesen Text kopieren und in Claude Code einfügen
Ich möchte ein vollautomatisches Instagram-Posting-System aufbauen mit Blotato. Bitte richte alles für mich ein.

Meine Nische: [HIER DEINE NISCHE EINTRAGEN — z.B. "Fitness für Frauen ab 40"]
Meine Zielgruppe: [HIER EINTRAGEN — z.B. "Frauen ab 40 die gesund abnehmen wollen"]
Mein Ton: [HIER EINTRAGEN — z.B. "motivierend, direkt, ohne Fachjargon"]
Posting-Uhrzeit: [HIER EINTRAGEN — z.B. "18:00 Uhr"]
Mein Blotato API-Key: [HIER EINTRAGEN — findest du in Blotato unter Settings → API]

Bitte erstelle: Contentplan CSV für 4 Wochen, PowerShell Skript für Blotato und erkläre mir danach Schritt für Schritt wie ich GitHub Actions einrichte.
Was passiert jetzt? Claude Code erstellt automatisch alle Dateien die du brauchst und führt dich durch die restliche Einrichtung. Folge einfach seinen Anweisungen.
5

Blotato mit Instagram verbinden (ca. 10 Min.)

Damit Blotato automatisch auf Instagram posten kann, muss dein Account einmal verbunden werden. Das machst du direkt in Blotato:

  1. Gehe auf my.blotato.com und logge dich ein
  2. Gehe zu Settings → Social Accounts
  3. Klicke auf Instagram und verbinde deinen Business Account
Was macht Blotato?

Blotato generiert aus deinem Prompt automatisch ein fertiges Video — mit KI-Bildern, Voiceover, eingeblendeten Untertiteln und postet es direkt auf Instagram. Einmal verbunden, läuft alles automatisch.

💬 Claude Code fragen wenn du nicht weiterkommst
Ich bin bei Blotato und komme nicht weiter. Ich sehe: [beschreibe was du siehst]. Was soll ich jetzt tun?
6

Automatischen Timer einrichten (ca. 15 Min.)

GitHub Actions startet dein System täglich zur eingestellten Uhrzeit — komplett in der Cloud, dein PC kann aus sein.

GitHub Actions (empfohlen)

Läuft komplett in der Cloud. Dein PC kann aus sein — der Post erscheint trotzdem pünktlich. Kostenlos. Das ist die professionelle Lösung.

💬 Claude Code fragen
Richte für mich GitHub Actions ein, damit mein Instagram Autopilot täglich um [UHRZEIT] automatisch startet — auch wenn mein PC aus ist.
Unser Tipp: Einmal einrichten — läuft dann für immer, egal ob dein PC an oder aus ist.
7

Ersten Post testen ✅

Bevor das System im Autopilot läuft, testen wir einmal gemeinsam:

💬 Claude Code fragen
Das System ist eingerichtet. Hilf mir jetzt einen Testlauf zu machen — was muss ich prüfen damit ich sicher bin dass alles funktioniert?
  • Testlauf gestartet
  • Blotato hat das Video generiert
  • Post ist auf Instagram erschienen ✅
8

Contentplan befüllen — das war's

Ab jetzt läuft alles automatisch. Deine einzige Aufgabe: einmal pro Woche oder Monat den Contentplan mit neuen Posts befüllen. Auch das erledigt Claude Code für dich:

💬 Claude Code fragen
Erstelle mir neue Posts für die nächsten 2 Wochen. Meine Nische ist [NISCHE], mein Ton ist [TON]. Füge sie direkt in meinen Contentplan ein.
🚀

Das System läuft.

Du hast jetzt ein vollautomatisches Instagram-Posting-System. Jeden Tag erscheint automatisch ein neuer Post — ohne dein Zutun.
