Schritt-für-Schritt Checkliste

Arbeite diese Liste von oben nach unten durch. Hake jeden Punkt ab wenn er erledigt ist.

Phase 1 — Accounts anlegen

  • Make.com Account erstellen

    make.com → kostenlos registrieren

  • fal.ai Account + API Key

    fal.ai → registrieren → API Keys → neuen Key erstellen → notieren

  • Creatomate Account + API Key

    creatomate.com → registrieren → API → Key notieren

  • Instagram auf Business umstellen

    Instagram App → Einstellungen → Konto → Zu professionellem Konto wechseln → Business

  • GitHub Account erstellen

    github.com → kostenlos registrieren

Phase 2 — GitHub einrichten

  • Öffentliches Repository anlegen

    GitHub → New Repository → Name: instagram-autopilot → Public → erstellen

  • Musik hochladen

    Ordner "music/" anlegen → MP3-Datei hochladen → URL notieren

Phase 3 — Creatomate Template

  • Template anlegen

    app.creatomate.com → Templates → New → Start from JSON → Inhalt von creatomate-template.json einfügen

  • Musik-URL anpassen + Template-ID notieren

    Eigene GitHub-URL eintragen → speichern → Template-ID aus Browser-URL notieren

Phase 4 — Make.com einrichten

  • Blueprint importieren

    Scenarios → neues Szenario → ... → Import Blueprint → make-blueprint.json hochladen

  • Verbindungen einrichten

    fal.ai, Creatomate und Instagram Business jeweils mit API Key verbinden

  • Template-ID eintragen

    Creatomate-Modul 20 → Body → DEINE-TEMPLATE-ID ersetzen

  • Szenario aktivieren + Webhook-URL notieren

    Toggle auf blau stellen → Webhook-Modul anklicken → URL kopieren

Phase 5 — Skript einrichten

  • Ordner anlegen + Dateien reinkopieren

    z.B. C:\Instagram-Autopilot\ → post-trigger-VORLAGE.ps1 und contentplan_vorlage.csv rein

  • Skript anpassen

    Die 3 Werte oben eintragen: CSV-Pfad, Webhook-URL, Log-Pfad

  • Windows Task Scheduler einrichten

    Aufgabenplanung → täglich 17:55 → powershell.exe → -ExecutionPolicy Bypass -File "C:\PFAD\post-trigger-VORLAGE.ps1"

Phase 6 — Testen

  • Skript manuell ausführen

    PowerShell öffnen → .\post-trigger-VORLAGE.ps1 → in Make.com prüfen

  • Render in Creatomate prüfen

    Ca. 2-4 Minuten warten → Video erscheint unter Renders

  • Instagram prüfen

    Reel erschienen? → Fertig. System läuft ab jetzt täglich automatisch.

Der Onboarding-Prompt

Komplett kopieren und in ChatGPT oder Claude einfügen. Die KI führt dich durch alles.

Prompt — alles markieren und kopieren
Du bist mein persönlicher Assistent für den Aufbau eines automatischen Instagram-Posting-Systems. Deine Aufgabe ist es, mich Schritt für Schritt durch das Onboarding zu führen. Gehe dabei GENAU so vor: SCHRITT 1 — BEGRÜSSUNG Begrüße mich kurz und erkläre in zwei Sätzen was jetzt passiert. SCHRITT 2 — PROFIL ABFRAGEN Stelle mir diese Fragen NACHEINANDER — immer nur eine auf einmal: Frage 1: "Wie heißt du?" Frage 2: "Was ist dein Instagram-Handle?" Frage 3: "Was ist dein Thema auf Instagram?" Frage 4: "Wer ist deine Zielgruppe? (Alter, Beruf, Problem)" Frage 5: "Was bietest du an?" Frage 6: "Was ist deine Website?" Frage 7: "Welches Stichwort sollen Follower kommentieren? (z.B. KLARHEIT)" Frage 8: "Eher direkt und klar — oder warm und einfühlsam?" Frage 9: "Für wie viele Tage soll ich den Plan erstellen?" SCHRITT 3 — ZUSAMMENFASSUNG Zeige mir eine Zusammenfassung und frage: "Ist das so richtig?" SCHRITT 4 — CONTENTPLAN ERSTELLEN Für jeden Post: ① CAPTION (150-200 Wörter, direkt, du-Form, endet mit: "Wenn das bei dir gerade so klingt: schreib [STICHWORT] in die Kommentare. Ich melde mich." + 3 Hashtags) ② TEXT-OVERLAY (genau 4 Zeilen, letzte Zeile: "Schreib [STICHWORT] – ich antworte dir") ③ VIDEO-PROMPT (englisch, Cinematic B-Roll, europäischer Mann Ende 50, 9:16, photorealistisch) SCHRITT 5 — TABELLE Alles als Tabelle ausgeben: Datum | Uhrzeit | Plattform | Post-Typ | Text | Link | Videoprompt | Text-Overlay | Status Fange jetzt mit Schritt 1 an.
Tipp: Klingt ein Post nicht nach dir, sag einfach: "Post 5 bitte nochmal — mehr wie ein Gespräch, weniger werblich." Die KI schreibt ihn sofort neu.
