Instagram Autopilot System
Setup-Anleitung
Detaillierte Erklärung — Schritt für Schritt.
Anleitung
1
Phase 1
Accounts anlegen
Make.com
Gehe auf make.com und erstelle einen kostenlosen Account. Make.com ist die Automatisierungsplattform, die alles zusammenhält — sie empfängt den Trigger, steuert fal.ai und Creatomate und postet auf Instagram.
fal.ai
Erstelle einen Account auf fal.ai. Gehe in dein Dashboard → API Keys → neuen Key erstellen. Diesen Key sofort notieren — er wird in Make.com eingetragen. fal.ai generiert das KI-Video aus deinem Videoprompt.
Creatomate
Erstelle einen Account auf creatomate.com (ab 29 $/Monat). Gehe in dein Dashboard → Account → API Access → API Key kopieren. Creatomate legt Text-Overlay und Musik auf das fertige Video.
Instagram auf Business umstellen
Öffne Instagram → Einstellungen → Konto → Zu professionellem Konto wechseln → Business. Ohne Business-Account kann Make.com nicht auf Instagram posten.
GitHub
Erstelle einen kostenlosen Account auf github.com. GitHub dient als Speicherort für deine Musikdateien — öffentlich erreichbar, kostenlos, zuverlässig.
2
Phase 2
GitHub einrichten
Repository anlegen
Gehe auf github.com → New repository. Name: instagram-autopilot. Sichtbarkeit: Public. README-Haken setzen. Repository erstellen.
Musik hochladen
Im Repository: "Add file" → "Create new file". Dateiname: music/deine-musik.mp3. Dann "Upload files" auswählen und die MP3 hochladen. Commit bestätigen.
Der Ordner music/ wird automatisch angelegt, wenn du den Dateinamen mit dem Slash eingibst.
Raw-URL notieren
Klicke auf die hochgeladene MP3 → "Raw" Button → URL aus der Adressleiste kopieren. Diese URL trägst du später ins Creatomate-Template und in die CSV ein.
Format: https://raw.githubusercontent.com/USERNAME/instagram-autopilot/master/music/dateiname.mp3
3
Phase 3
Creatomate Template anlegen
Template aus JSON erstellen
Gehe auf app.creatomate.com → Templates → New Template → "Start from JSON". Kopiere den gesamten Inhalt der mitgelieferten Datei creatomate-template.json und füge ihn ein. Bestätigen.
Musik-URL anpassen
Im JSON-Editor: suche nach der Musik-URL und ersetze sie durch deine eigene GitHub Raw-URL aus Phase 2. Dann speichern.
Template-ID notieren
Nach dem Speichern siehst du in der Browser-URL deine Template-ID. Sie steht nach /templates/ und sieht aus wie eine lange Buchstaben-Zahlen-Kombination. Diese ID gleich notieren.
Beispiel: app.creatomate.com/templates/abc123def456/edit — der fett markierte Teil ist deine ID.
4
Phase 4
Make.com einrichten
Blueprint importieren
Gehe auf make.com → Scenarios → oben rechts auf "Create a new scenario". Im leeren Szenario oben rechts auf die drei Punkte (…) klicken → "Import Blueprint" auswählen → Datei make-blueprint.json hochladen. Das Szenario baut sich automatisch auf.
fal.ai Verbindung einrichten
Klicke auf das fal.ai-Modul im Szenario → "Add" bei der Verbindung → API Key aus Phase 1 eintragen → speichern.
Creatomate Verbindung einrichten
Klicke auf das Creatomate-Modul → "Add" bei der Verbindung → API Key aus Phase 1 eintragen → speichern.
Instagram Business Account verbinden
Klicke auf das Instagram-Modul → "Add" → mit deinem Facebook/Instagram Business Account einloggen und Zugriff erlauben.
Template-ID in Modul 20 eintragen
Öffne das Creatomate-Modul (Modul 20) im Szenario. Im Feld "Body" steht DEINE-TEMPLATE-ID — ersetze das durch die Template-ID aus Phase 3.
Der Body soll danach so aussehen:
{ "template_id": "DEINE-TEMPLATE-ID", "modifications": { "video.source": "{{3.data.video.url}}", "overlay_text": "{{1.textoverlay}}", "music.source": "{{1.musikurl}}", "video.volume": 0, "music.volume": 4 } }
Szenario aktivieren
Unten links im Szenario den Toggle auf aktiv stellen — er muss blau leuchten.
Wichtig Wenn der Toggle grau ist, ist das Szenario inaktiv — dann kommt kein Webhook an und nichts wird gepostet. Immer prüfen, dass er blau/aktiv ist.
Webhook-URL kopieren
Klicke auf das erste Modul im Szenario (Webhook). Dort findest du die Webhook-URL. Diese URL komplett kopieren und sicher notieren — sie kommt in das PowerShell-Skript.
5
Phase 5
Skript und Plan einrichten
Ordner anlegen
Erstelle einen neuen Ordner auf deinem Computer, z. B. C:\Instagram-Autopilot\. Alle Projektdateien kommen hier rein.
Vorlagen reinkopieren
Kopiere post-trigger-VORLAGE.ps1 und contentplan_vorlage.csv aus dem Paket in diesen Ordner.
Skript konfigurieren
Öffne post-trigger-VORLAGE.ps1 mit dem Editor (Rechtsklick → Bearbeiten). Ganz oben stehen drei Zeilen zum Ausfüllen: Pfad zur CSV-Datei, Webhook-URL und Pfad für die Log-Datei. Alle drei eintragen und speichern.
Contentplan eintragen
Erstelle deinen Contentplan per KI (Anleitung in contentplan-per-ki.html) und trage die Posts in die CSV-Datei ein. Jede Zeile ist ein Post.
Windows Task Scheduler einrichten
Öffne den Windows Task Scheduler (Aufgabenplanung). Neue Aufgabe erstellen:
Trigger: Täglich, 17:55 Uhr
Aktion — Programm: powershell.exe
Aktion — Argument: -ExecutionPolicy Bypass -File "C:\DEIN-PFAD\post-trigger-VORLAGE.ps1"
6
Phase 6
Testen
Skript manuell ausführen
PowerShell als Administrator öffnen. Befehl eingeben: & "C:\DEIN-PFAD\post-trigger-VORLAGE.ps1". Das Skript sucht in der CSV nach dem heutigen Datum und feuert den Webhook.
Make.com prüfen
Gehe in Make.com → Scenarios → dein Szenario → "History". Ein neuer Eintrag sollte erscheinen (grüner Haken = Erfolg).
Creatomate prüfen
Gehe auf app.creatomate.com → Renders. Der aktuelle Render sollte erscheinen. Status wechselt von "Queued" zu "Rendering" zu "Done" — dauert 2–4 Minuten.
Instagram prüfen
Öffne dein Instagram-Profil. Das fertige Reel sollte erschienen sein — mit Text-Overlay, Musik und Caption.
Fertig Ab jetzt läuft das System täglich automatisch. Du musst nichts mehr tun, außer einmal im Monat einen neuen Contentplan per KI zu erstellen.
