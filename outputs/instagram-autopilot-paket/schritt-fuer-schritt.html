Instagram Autopilot System
Schritt-für-Schritt Checkliste
Von Null bis zum ersten automatischen Post.
Checkliste
1
Phase 1
Accounts anlegen
  • Make.com Account erstellen make.com — kostenlos
  • fal.ai Account erstellen + API Key notieren fal.ai
  • Creatomate Account erstellen + API Key notieren creatomate.com — ab 29 $/Monat
  • Instagram auf Business umstellen: Einstellungen → Konto → Business
  • GitHub Account erstellen github.com — kostenlos
2
Phase 2
GitHub einrichten
  • Neues öffentliches Repository anlegen — Name: instagram-autopilot, Public
  • Musik-Ordner music/ anlegen + MP3 hochladen
  • URL notieren: https://raw.githubusercontent.com/USERNAME/instagram-autopilot/master/music/dateiname.mp3
3
Phase 3
Creatomate Template anlegen
  • app.creatomate.com → Templates → New Template → "Start from JSON" → Inhalt von creatomate-template.json einfügen
  • Musik-URL im JSON auf eigene GitHub-URL anpassen
  • Template speichern → Template-ID aus der Browser-URL notieren
4
Phase 4
Make.com einrichten
  • Blueprint importieren: Scenarios → neues Szenario → … → "Import Blueprint" → make-blueprint.json hochladen
  • fal.ai Verbindung einrichten (API Key eintragen)
  • Creatomate Verbindung einrichten (API Key eintragen)
  • Instagram Business Account verbinden
  • Im Creatomate-Modul (Modul 20): DEINE-TEMPLATE-ID durch eigene ID ersetzen
  • Szenario-Toggle auf aktiv (blau) stellen
  • Webhook-URL kopieren und notieren
5
Phase 5
Skript und Plan einrichten
  • Ordner anlegen, z. B. C:\Instagram-Autopilot\
  • post-trigger-VORLAGE.ps1 und contentplan_vorlage.csv in den Ordner kopieren
  • post-trigger-VORLAGE.ps1 öffnen — die 3 Werte oben eintragen: CSV-Pfad, Webhook-URL, Log-Pfad
  • Contentplan per KI erstellen (siehe contentplan-per-ki.html) und in CSV eintragen
  • Windows Task Scheduler: täglich 17:55 Uhr, Programm powershell.exe, Argument: -ExecutionPolicy Bypass -File "C:\PFAD\post-trigger-VORLAGE.ps1"
6
Phase 6
Testen
  • PowerShell öffnen → Skript manuell ausführen
  • In Make.com prüfen, ob Webhook angekommen ist
  • In Creatomate prüfen, ob Render läuft (2–4 Minuten)
  • Auf Instagram prüfen, ob Reel erschienen ist
  • Fertig — läuft ab jetzt täglich automatisch.
