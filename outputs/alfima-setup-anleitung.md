# Alfima Setup — Schritt für Schritt
# Produkt: YouTube auf Autopilot
# Datei: youtube-automation-produkt-v1.0.zip

---

## Schritt 1: Einloggen und neues Produkt anlegen

1. alfima.com aufrufen und einloggen
2. Dashboard → "Produkte" → "Neues Produkt erstellen"
3. Produkttyp: **Digitales Produkt** wählen

---

## Schritt 2: Grunddaten eintragen

**Produktname:**
```
YouTube auf Autopilot
```

**Kurzbeschreibung** (erscheint in der Produktübersicht, ca. 1-2 Sätze):
```
Vollautomatische YouTube-Produktion per KI. Du wählst ein Thema — Claude schreibt, spricht, schneidet und lädt hoch. Zwei Entscheidungen. Ein fertiges Video.
```

**Kategorie:** Software / Tools (oder "Digitale Produkte" falls keine Unterkategorie)

---

## Schritt 3: Verkaufsbeschreibung (langer Text)

Kopiere den gesamten Text aus `outputs/alfima-verkaufstext.md` — von der Headline bis zum FAQ.

Formatierung in Alfima:
- Überschriften fett machen
- Absätze so lassen wie sie sind
- Den Button-Text [JETZT KAUFEN — 397 Euro] entfernen — Alfima setzt den Kaufbutton automatisch

---

## Schritt 4: Preis

**Preis:** 397,00 EUR
**Steuer:** 19% MwSt. (wird automatisch berechnet)
**Zahlungsarten:** alle verfügbaren aktivieren (Kreditkarte, PayPal, SEPA)
**Ratenzahlung:** nein (Einmalzahlung)

---

## Schritt 5: Digitale Lieferung einrichten

1. "Digitale Datei hochladen" auswählen
2. Die Datei hochladen: `outputs/youtube-automation-produkt-v1.0.zip`
3. Download-Limit: **unbegrenzt** (Käufer soll jederzeit neu downloaden können)
4. Download-Link läuft ab nach: **nie** oder längstmöglicher Zeitraum

**E-Mail nach Kauf** (wird automatisch verschickt):
```
Betreff: Dein YouTube auf Autopilot Workspace

Hallo [Name],

vielen Dank für deinen Kauf.

Hier ist dein Download-Link:
[DOWNLOAD-LINK]

Was als nächstes:
1. ZIP-Datei herunterladen und entpacken
2. Ordner in Claude Code öffnen
3. /setup tippen — Claude führt dich durch alles

Bei Fragen melde dich unter: [DEINE E-MAIL]

Viel Erfolg,
Andreas Stock
```

---

## Schritt 6: Produktbild / Thumbnail

Du brauchst ein Produktbild für die Alfima-Seite.
Empfohlene Größe: 1280x720 px

Schnellste Lösung: Canva öffnen, YouTube-Thumbnail-Format wählen.

Text auf dem Bild:
- Große Schrift oben: "YouTube auf Autopilot"
- Kleinere Schrift darunter: "Zwei Entscheidungen. Ein fertiges Video."
- Dunkler Hintergrund, helle Schrift
- Optional: Screenshot vom laufenden Terminal oder YouTube Studio

---

## Schritt 7: Rechtliches

**AGB:** Falls noch keine vorhanden — Alfima hat oft einen Generator für digitale Produkte.
**Widerrufsrecht:** Bei digitalen Produkten die sofort geliefert werden kann das Widerrufsrecht ausgeschlossen werden — aber nur wenn der Käufer vor dem Kauf ausdrücklich zustimmt. Alfima regelt das meist automatisch.
**Impressum:** Muss auf der Verkaufsseite verlinkt sein.

---

## Schritt 8: Testlauf vor dem Launch

1. Produkt auf "Entwurf" lassen (noch nicht öffentlich)
2. Testkauf mit eigener E-Mail durchführen (Alfima hat meist eine Testfunktion)
3. Prüfen ob Download-Link in der Bestätigungsmail ankommt
4. ZIP herunterladen und prüfen ob alle Dateien drin sind
5. Erst dann auf "Veröffentlicht" schalten

---

## Schritt 9: Launch-Link holen

Nach Veröffentlichung:
- Produkt-URL kopieren
- In `outputs/launch-posts.md` an allen Stellen wo [LINK] steht eintragen
- In der Instagram-Bio hinterlegen
- In LinkedIn-Posts einfügen

---

## Zusammenfassung Reihenfolge

1. Alfima-Produkt anlegen und alles eintragen
2. Produktbild in Canva erstellen und hochladen
3. Testkauf durchführen
4. Bewusst Einfach Video abwarten — als Beispielvideo verlinken
5. Produkt auf "Öffentlich" schalten
6. Teaser-Post auf Instagram und LinkedIn
7. Zwei bis drei Tage später: Launch-Post mit Link
