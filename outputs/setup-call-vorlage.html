Instagram Reel Autopilot

Komplett-Service · Setup Call · ca. 90 Minuten

Teil 1 — Informationen aufnehmen

15 Min.

Teil 2 — Accounts einrichten

10 Min.
  • Instagram Business Account aktiv
  • fal.ai Account erstellt + mind. 10 USD Guthaben
  • Make.com Account erstellt
  • Creatomate Account erstellt
  • Facebook Developer Account vorhanden

Teil 3 — Claude Code Setup

20 Min.
  • Claude Code geöffnet
  • Setup-Prompt eingefügt — Nische, Zielgruppe, Ton eingetragen
  • Contentplan CSV erstellt und befüllt (mind. 2 Wochen)
  • PowerShell Skript erstellt (post-trigger.ps1)
  • Pfade im Skript geprüft

Teil 4 — Make.com einrichten

20 Min.
  • Blueprint importiert
  • Instagram Business Verbindung hergestellt
  • fal.ai API Key eingetragen (Reel-Pfad + Foto-Pfad)
  • Creatomate API Key + Template ID eingetragen
  • Webhook URL kopiert und ins PowerShell Skript eingetragen
  • Szenario auf ON gestellt

Teil 5 — Windows Task Scheduler

10 Min.
  • Aufgabe angelegt
  • Trigger: täglich zur gewählten Uhrzeit
  • Skript-Pfad korrekt eingetragen
  • ExecutionPolicy Bypass gesetzt

Teil 6 — Testlauf

10 Min.
  • Datum im CSV auf heute gesetzt, Status: geplant
  • Skript manuell gestartet
  • Log geprüft (post-trigger-log.txt)
  • Make.com History geprüft
  • Instagram geprüft — Post erschienen ✅

Teil 7 — Übergabe

5 Min.
  • Kunde weiß wie er den Contentplan befüllt
  • Kunde weiß wo das Log liegt
  • Nächste Schritte erklärt
