# Meine Commands — Spickzettel

## Session starten
```
/prime
```
Immer zuerst eingeben. Lädt den kompletten Kontext.

---

## Minikurs / Produkt entwickeln
```
/minikurs-generator
```
Führt dich Schritt für Schritt durch: Zielgruppe, Kursstruktur, Offer Audit, Viralitäts-Score.
Am Ende: vollständiges Konzept, gespeichert.

---

## Inhalt recherchieren + Video-Idee entwickeln
```
/research
```
Analysiert Nische, generiert fünf Video-Ideen, schreibt komplettes Skript.

---

## Video produzieren (YouTube Automation)
```
/produce
```
Startet die vollautomatische Videoproduktion. Vorher /research ausführen.

---

## Neuen Plan erstellen
```
/create-plan [was du willst]
```
Beispiel: /create-plan Salespage für Nein aus Überzeugung erstellen

---

## Plan umsetzen
```
/implement plans/dateiname.md
```
Setzt einen erstellten Plan Schritt für Schritt um.

---

## Ersteinrichtung (Neukunde / neuer Workspace)
```
/setup
```
Einmaliger Setup-Assistent — API-Keys, OAuth, Testlauf.

---

## Session beenden
```
/shutdown
```
Zusammenfassung, offene Punkte, nächster Schritt — alles gespeichert.
