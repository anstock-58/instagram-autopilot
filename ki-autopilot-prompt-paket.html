Füge jeden Prompt in Claude oder ChatGPT ein und bekomm in Sekunden einen fertigen Reel-Text für deinen Account.

Content-Ideen, leeres Dokument, kein Anfang — das kennt jeder der auf Instagram postet. Diese 30 Prompts nehmen dir genau das ab.

Kopiere einfach den Prompt der zum heutigen Tag passt, füge ihn in Claude oder ChatGPT ein, ersetze die markierten Felder — und dein Text ist fertig.

⚡ So nutzt du dieses Paket

  1. Wähle den Prompt der zum heutigen Thema passt
  2. Kopiere ihn vollständig
  3. Öffne Claude (claude.ai) oder ChatGPT
  4. Füge den Prompt ein und ersetze die [MARKIERTEN FELDER] mit deinen Angaben
  5. Fertig — poste den Text direkt auf Instagram
